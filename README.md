# 👟 Nike Personal Landing Page

A modern and responsive **Nike-inspired landing page** built using **React.js** and **Tailwind CSS**, focused on delivering a clean UI and smooth user experience.

---

## 📌 Overview

This project is a **personal frontend project** inspired by Nike’s branding and design style.

The goal was to:
- Build a clean and modern UI  
- Practice real-world landing page structure  
- Improve React component architecture  
- Create a fully responsive design  

---

## ✨ Features

- ⚡ Modern and stylish UI inspired by Nike  
- 📱 Fully responsive (Mobile, Tablet, Desktop)  
- 🧩 Reusable React components  
- 🛍️ Product showcase sections  
- 🎯 Smooth layout and user-friendly structure  

---

## 🛠️ Tech Stack

- **React.js**  
- **Tailwind CSS**  
- **JavaScript (ES6+)**  
- **Vite**  

---

## 🚀 Getting Started

```bash
git clone https://github.com/eslamahmedbadea/Nike_Personal_Landing_Page.git
cd Nike_Personal_Landing_Page
npm install
npm run dev
```
